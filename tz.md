# Техническое задание

1. Один самодостаточный index.html (HTML+CSS, без сборки и внешних зависимостей).
2. Структура: шапка → hero с ключевыми цифрами → блоки проектов (6 карточек) → перспективы → подвал с CTA.
3. Контент — строго из brief.md; цифры не менять и не округлять.
4. Места под визуальные материалы: каждая карточка проекта содержит зарезервированный блок «визуал» с подписью (скриншоты добавит заказчик).
5. Адаптивность: 390 px и 1440 px.
6. Доступность: контраст текста, семантические заголовки, alt-подписи.
7. Язык — русский; тон — из brief.md.
